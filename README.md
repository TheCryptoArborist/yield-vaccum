# Topaz: Yield Vacuum

An independent educational arcade game about Topaz DEX on BNB Chain, presented by The Crypto Arborist.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The project is configured for a standalone Netlify deployment. Its shared weekly leaderboard uses Netlify Blobs and does not depend on the TREE website or its infrastructure.
